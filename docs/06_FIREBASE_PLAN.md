# 06 — Firebase Plan

Firebase handles realtime concerns for RAPEX:
- Push notifications
- Realtime chat (support chat, in-app messaging)
- Presence
- Typing indicators
- R.E.X. (mascot) conversation state — AI decides emotion, app plays the matching animation

This doc will track Firebase project setup, collections/paths used for each of the above, and security rules once implementation begins.
