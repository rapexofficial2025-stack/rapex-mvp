# 07 — UI Guidelines

UI for RAPEX is generated in Base44 (components, layouts, navigation, responsive design), then converted by Claude into the app folders under `apps/`. Base44 never touches backend logic.

This doc will track:
- Design tokens (colors, spacing, typography) once defined
- Component conventions for converting Base44 output into `src/components/`
- Navigation conventions per app
