# Business Rules — Overview

This is RAPEX's business rules library: one document per rule area. Each file will hold the authoritative logic definition (inputs, outputs, edge cases, formulas) as it's decided — most will be filled in alongside the Xano backend design conversation, since Xano implements exactly what's specified here.

**Hard rule (already decided):** business logic is implemented in Xano, never in the frontend apps. These docs describe *what* the rules are; Xano implements *how*.
