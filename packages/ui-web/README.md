# @rapex/ui-web

React (DOM) component library for RAPEX's desktop-first apps: **Merchant Portal**, **Admin Portal**, **Provider Portal**. Built on `@rapex/theme` / `@rapex/constants` / `@rapex/utils`. Plain React DOM + inline styles, not React Native Web — `@rapex/ui-native` is the separate, RN-native equivalent for the mobile apps. Same design tokens, different rendering, per platform.

## Built (atoms + shell)
`Button`, `Input`, `Badge`, `GlassCard`, `Loading`, `Skeleton`, `EmptyState`, `ErrorState`, `Toast` (+ `ToastProvider`/`useToast`), `Sidebar`, `Topbar`

## Backlog (not built yet)
Search Bar, Filter Panel, Notification Panel, Drawer, Modal, Glass Widget, Status Badge, Chart Container, Data Table, Audit Table, User Table, Merchant Table, Order Table, Wallet Table, Dashboard Card, Statistics Card, Revenue Card, Analytics Card, Commission Card, Ledger Card

## Status
Foundational + shell layer only (Sidebar/Topbar are ready for Sprint FE-03's Merchant/Admin navigation). Table and dashboard-card components come once each portal's real screens need them.
