# @rapex/constants

Shared constant values used across RAPEX apps: `Role` (customer/rider/merchant/provider/admin) and `PilotArea` (Imus, Kawit, Lancaster, General Trias).

Business-rule-dependent enums (order status, auction status, wallet transaction types, etc.) are not defined here yet — they belong to Xano's business logic and must match what's actually implemented there. See [docs/business/](../../docs/business/00_OVERVIEW.md).
