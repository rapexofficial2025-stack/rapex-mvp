# assets/

Shared, cross-app binary assets. Base44 drops generated assets directly into the matching folder below; app-specific assets that never get reused stay inside that app's own `assets/` folder instead (e.g. `apps/customer-app/assets/`).

| Folder | Contents |
|---|---|
| `images/` | General raster images not covered by a more specific folder |
| `icons/` | UI icon set (non-category) |
| `illustrations/` | Larger illustrative artwork (empty states, onboarding, etc.) |
| `animations/` | General animation assets |
| `lottie/` | Lottie JSON animation files |
| `rex/` | R.E.X. mascot art and animation frames (idle, happy, thinking, sad, delivery, typing, speaking, celebration, loading, error, walking, pointing) |
| `sounds/` | Sound effects and audio cues |
| `fonts/` | Brand typeface files, once chosen |
| `categories/` | Marketplace category icons/imagery |
| `products/` | Placeholder/default product imagery |
| `stores/` | Placeholder/default store imagery |
| `banners/` | Promo and marketing banner imagery |
| `avatars/` | Default/placeholder user avatars |
| `placeholders/` | Generic placeholder/fallback imagery used across apps |

## Status
Folders created, empty. All content pending — this structure exists so Base44-generated assets have a defined home from day one.
